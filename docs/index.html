What it does

It wraps the OpenAI Agents SDK so that when an agent calls a paid tool, it pays in Nano (XNO) over the HTTP 402 (x402) protocol. No API keys, no accounts, no bridge — just a Nano wallet.

  • Instant finality (~0.3s)
  • Zero transaction fees
  • No issuer can freeze funds
  • No stablecoin exposure
  • Drop-in XP402Payer for any OpenAI Runner
